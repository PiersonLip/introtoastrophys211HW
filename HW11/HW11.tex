\subsubsection{}
Given\dots
\[v_{esc} = \sqrt{\frac{2GM}{R}}\]
\[v_{esc} = 500 \text{km} \text{s}^{-1} \qquad 8.5 \text{kpc}\]
We find that
\dots
\[v_{esc} = \frac{\sqrt{2GM}}{\sqrt{R}}\]
\[\frac{v_{esc}\sqrt{R}}{\sqrt{2G}} = \sqrt{M}\]
\[M = \SI{2.470e+11}{\Msun}\]
